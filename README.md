# Umrechner

Ein übersichtlicher, kategorisierter Einheitenumrechner für alle gängigen Maßeinheiten.

**Funktionen**
- Kategorien: Länge, Masse, Fläche, Volumen, Temperatur, Geschwindigkeit, Leistung, Energie, Druck, Kraft, Zeit, Winkel, Datenmenge
- Direkte Umrechnung von Quelle zu Ziel
- 100% offline, keine Installation nötig
- Open Source

## Nutzung
1. `umrechner.html` im Browser öffnen
2. Kategorie wählen
3. Einheit von / Einheit nach wählen
4. Wert eingeben → Ergebnis wird sofort berechnet

## Dateien
- `umrechner.html` – kompletter Umrechner als Single-File, im Browser öffnen
- `umrechner.py` – ausführbare Python-Version mit tkinter
