# 🧮 Umrechner – Einheitenumrechner
> Übersichtlicher, kategorisierter Einheitenumrechner für alle gängigen Maßeinheiten. 100% offline, Single-File.

![Kategorien](https://img.shields.io/badge/Kategorien-13-f77f6f?style=for-the-badge)
![Open Source](https://img.shields.io/badge/Open%20Source-MIT-4f8cff?style=for-the-badge)

## 🎯 Über dieses Projekt
Eine **Single-File HTML-Anwendung** mit JavaScript, die eine schnelle und übersichtliche Umrechnung in 13 Kategorien ermöglicht.
Kein Server, keine Installation – einfach öffnen und loslegen.

**Repo Owner:** molex2go

## ✨ Features
| Feature | Beschreibung |
|---|---|
| 📂 Kategorisiert | Länge, Masse, Fläche, Volumen, Temperatur, Geschwindigkeit, Leistung, Energie, Druck, Kraft, Zeit, Winkel, Datenmenge |
| ⚡ Sofort | Live-Berechnung ohne Reload |
| 💾 Offline | Läuft komplett lokal im Browser |
| 📱 Responsive | Desktop, Tablet & Smartphone |
| 🛠️ Open Source | MIT Lizenz |

## 🚀 Verwendung
### Direkt im Browser öffnen
1. `umrechner.html` herunterladen oder im Repo öffnen
2. Kategorie wählen
3. Einheit von / Einheit nach wählen
4. Wert eingeben → Ergebnis wird sofort angezeigt

### Online nutzen
👉 **https://github.com/molex2go/Umrechner/blob/main/umrechner.html**
Direkt im Browser öffnen oder lokal speichern.
